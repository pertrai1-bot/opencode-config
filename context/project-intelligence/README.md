# Project Intelligence

Project intelligence stores durable knowledge about this config repo itself.

## What Belongs Here

- Decisions about config structure, workflow policy, and cross-cutting conventions.
- Reusable patterns discovered while maintaining this config.
- Maintenance notes that should survive beyond one session.

## What Does Not Belong Here

- Temporary task handoffs.
- Project-specific product or business domain knowledge.
- Full copies of skills, agents, commands, or rule packs.
- Secrets, credentials, or private local environment details.

## Sections

- `decisions/` records durable config decisions with alternatives and consequences.
- `patterns/` records repeated useful practices that future agents should reuse.

## Reading Rule

Read the `README.md` for the relevant section first, then open only matching decision or pattern files.
